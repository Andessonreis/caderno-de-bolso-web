  - [cartao.png](telas/cartao.png): cartão com QR para a banca
  - [visita.png](telas/visita.png): roteiro de apoio à visita, etapa Documentos
  - As demais telas (ficha sem código e com código ruim, formulário de ficha, lista de visitas,
    etapas 1 a 7, resumo e página não encontrada) aparecem no [documento de fluxos](fluxos.md),
    cada uma na sua seção.
